**Ember Duel** is an original turn-based card battler: you are the Ember Keeper, duelling Cinder, the Ember AI, across a tavern table. Four suits — Flame 🔥, Leaf 🍃, Tide 💧, Spark ⚡ — each with its own colour and shape. Spend mana that grows every turn, chain two cards of the same suit for +2 attack, shield yourself, heal, draw, and burn the foe's 30 life to zero before yours runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a card to select it, click again (or press Enter) to play it. Keys: 1–7 pick a card, Enter plays it, E ends the turn, M mutes. No network needed — the game is plain static files under `game/`, and its sounds are synthesized in the browser.

## Shots

The game renders fixed demo states for screenshots: `?shot=start` (title), `?shot=play` (mid-game table), `?shot=win` (victory), `?shot=loss` (defeat).
